# 🛒 E-Commerce Website

A full-stack E-Commerce web application built to provide users with a smooth online shopping experience. This project includes product browsing, cart management, user authentication, and order handling.

---

# 🚀 Features

* User Registration & Login
* Product Listing Page
* Search and Filter Products
* Add to Cart Functionality
* Responsive Design
* Product Details Page
* Order Management
* Secure Authentication

---

# 🛠️ Tech Stack

## Frontend

* HTML
* CSS
* JavaScript
* React.js 


## Backend

* Node.js
* Express.js

## Database

* MongoDB

# 🔐 Environment Variables

Create a `.env` file and add the following:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
```
